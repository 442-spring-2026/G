Testing plan:

Type of testing:

- Manual acceptance testing

Testing process:

- Developers will test once each issue is completed. 


Test environments:

- The testing environment will be on the developer’s local machine.

Failure protocol:

- If a bug is found:

  - The tester will document it by adding a new issue. An example of how an issue will be named is “Bug: #2”, where #2 refers to the issue number that the bug is associated with.

- The issue should contain: 

  - Description of the problem
  
  - What steps were taken to resolve it
  
  - Status: Resolved/Not Resolved
  
- The person who tested it will be assigned to fix that bug.

- If the person is unable to resolve the bug immediately, they will mark the bug as “Not Resolved” and communicate that with the group and other members will be assigned to help them out.
