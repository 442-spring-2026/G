## Local React App Setup

1. Install dependencies:
   * `npm install`
2. Create `.env` from `.env.example` and fill in Firebase config values (ask a developer for the values).
3. Start the app:
   * `npm run dev`
4. Open the localhost URL shown in the terminal (usually `http://localhost:5173/login`).
